# Managed biography search visibility

The public profile shell remains shared across all 16 languages. `_worker.js` renders the published `listSiteTeam` card into that shell for everyone, including ordinary browsers and search crawlers. No separate founder biography, copied text, credentials or private Console data is stored in this repository.

Current published portraits have source-specific 640px WebP presentation variants. Matching uses the immutable source object path without its public download token; a changed photo path immediately falls back to the new Console image, so variants cannot pin an old portrait over a later update. The original upload is retained. The founder portrait's transfer size drops from 1,897,898 to 27,818 bytes at the current 160px display size.

`_routes.json` limits edge execution to biography addresses and `sitemap-profiles.xml`. Other pages, checkout, legal readers and assets keep their static hosting path. Profile HTML uses a unique title/description, one canonical, actual-language alternates, social metadata and ProfilePage/Person JSON-LD. The existing founder alias remains the clean canonical URL; ID-based profiles remain available for every other published biography. Preview deployments and untranslated fallback variants are noindex.

The directory is fetched using a fixed public endpoint with an eight-second deadline, in-flight deduplication and a bounded 16-language in-memory/edge cache for 60 seconds. Browser cookies and authorization headers are never forwarded. A missing card or biography returns 404; unavailable upstream data returns 503/no-store/Retry-After instead of an indexable empty success page. All inserted text, attributes and JSON are escaped. The initial browser hydration uses only the selected language's public card and makes no redundant directory request.

Google discovers the current public profiles through the second Sitemap directive in robots.txt. Sitemap entries and reciprocal language links are derived from actual public translations, without invented modification timestamps. Console publication changes are reflected after the bounded cache expires. Removing a biography removes it from the next sitemap and yields 404 after cache expiry.

Checks: `npm test` covers rendering without JavaScript, XSS, URL handling, canonical/structured data, 404/503/HEAD, scope restrictions and hydration. `npm run test:seo` audits the static site, while intentional noindex templates are checked separately through their rendered response tests. The live audit workflow measures Performance, Accessibility, Best Practices and SEO on mobile and desktop for the homepage and biography. Its Lighthouse JSON artifacts are measurements, not promises about Google ranking; Search Console indexing/recrawl remains a separate verified-property operation.

The canonical founder path is now `/{lang}/mustafa`. Previous `mustafa-caki`, legacy team aliases and ID/slug-based founder addresses redirect with HTTP 301; language selection and all metadata use the new address. The static homepage links use the canonical address directly.

`scripts/public-page-inventory.cjs` classifies every static public canonical page. `scripts/build-sitemap.cjs` derives the full static sitemap without invented lastmod values and CI rejects stale sitemap entries. Beacon's 16 localized pages expose reciprocal language alternates. Published biographies remain in the dynamic sitemap. Authentication/action links (reset, invitation activation), error responses, untranslated biography fallbacks and preview deployments are operational resources, not public content pages, and retain noindex. Vertex Console retains its independent noindex policy.

`performance-pages.json` separates seven public page classes and their critical/deferred work, with a target of 100 in each Lighthouse category on both devices. The workflow reports actual results for all seven classes; targets are not substituted for measurements. Homepage sections below the opening viewport use content-visibility:auto so their DOM remains searchable/accessible while expensive layout and font shaping is deferred. The hero waits only for its own title glyphs, not every font on the page.
